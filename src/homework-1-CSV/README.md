После того, как программа собрана с помощью CMake, ее можно запускать через консоль с помощью этих строк:\

```
copy build\main.exe .
.\main.exe input.csv output.txt
```

input.csv - исходный файл с данными в формате CSV (должен быть в папке homework-1-CSV).\
output.txt - название файла, где будет отрисована таблица с данными (файл создается автоматически).
